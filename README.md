# 聚合支付后台二次开发说明

本仓库是“基于 SpringBlade 的聚合支付后台二次开发”的面试证据与说明仓库，不复制或伪称拥有 SpringBlade、Saber、JeePay 等上游框架源码。

## 项目定位

在 SpringCloud/SpringBlade 基础上，围绕聚合支付课程需求完成商户、商户应用、支付方式、支付接口配置、商户中心与支付宝沙箱支付链路的学习与二次开发。

## 已核对的功能范围

- 商户管理：新增、编辑、删除、批量删除。
- 商户应用：应用 CRUD，新增商户时创建默认应用，删除商户时清理应用。
- 支付配置：支付方式、支付接口定义、接口配置与图片上传。
- 支付操作：统一下单入口、按条码识别支付方式、支付参数与商户配置读取、支付订单创建及渠道返回处理。
- 前端：商户、应用、支付配置、支付中心页面。

## 来源与边界

- 基础后端框架：SpringBlade。
- 基础前端框架：Saber。
- 支付通道相关实现中存在 JeePay 版权头及上游实现。
- 本项目不能描述为“从零实现支付平台”或“独立实现所有支付通道”。
- `jar-dev` 仅包含基础 Blade 服务包，未包含 `blade-sypay.jar`，因此不将其描述为完整支付服务部署包。

## 推荐的面试表述

> 基于 SpringCloud / SpringBlade 的聚合支付后台二次开发：围绕商户、商户应用、支付方式及支付接口配置完成后台管理功能，并在支付宝沙箱环境梳理统一下单与渠道调用链路。
